# Restaurant Landing Page

This is a responsive restaurant landing page that I built as a frontend project.

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- GSAP
- ScrollTrigger
- Lenis

## Features

- Responsive design
- Smooth scrolling
- Scroll animations
- Interactive sections
- Mobile-friendly layout
- Modern restaurant UI
